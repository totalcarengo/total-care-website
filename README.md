# Total Care Website

Static responsive website for **Total Care – A Non Governmental Organisation**, based on the supplied brochure.

## Files

- `index.html` – main website
- `styles.css` – website styling
- `script.js` – mobile navigation
- `assets/` – HD website images
- `favicon.svg` – browser icon

## View locally

Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `total-care-website`.
2. Upload all files and folders from this project **into the root of the repository**. `index.html` must remain at the top level.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show the published website URL in the Pages section.

The site uses only relative file paths, so it is ready for GitHub Pages as provided.
